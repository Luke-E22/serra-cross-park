# SignPanel

A panel built like the park's interpretive sign: a colored band with the title, serif text below, and an optional photo.

- **Provide:** `title`, `children` (paragraphs), `tone`, and an optional `image`, `imageAlt` and `caption`.
- Tones follow the sign: `green` for the Cross and its history, `navy` for the stonework and facts, `brick` for the map and directions, `ochre` for the Thomas Fire and restoration.
- Use it for History and Visit content, not for wedding sales copy.
