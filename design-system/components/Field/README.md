# Field

A label, a control, and help or error text. Every form on the site is built from these.

- **Provide:** `label`, `name`, `type` (`text`, `email`, `tel`, `date`, `number`, `select` with `options`, or `textarea`), `optional`, `help`, `error`, and the usual value props.
- Fields are required by default. Optional ones say "Optional" beside the label.
- Labels are nouns in display capitals. Errors say what to do: "The park holds up to 500 standing guests."
- Inputs are `surface-raised` with a `line-strong` border. Place forms on `surface-alt` or `surface`.
