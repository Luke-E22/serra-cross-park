# SectionHeading

Eyebrow, title and intro that open a section of a page.

- **Provide:** `title`, an optional `eyebrow` of one to three words, an `intro` (lede paragraph), `size` (`lg` uses `display-lg` for page sections, `md` uses `heading` for subsections), `align` (`center` for showcase sections, `left` elsewhere), `ornament` to add the dotted-O rule (centered sections only), `onDark` on navy, and `as` for the heading level.
- Keep titles under eight words, with no closing period.
