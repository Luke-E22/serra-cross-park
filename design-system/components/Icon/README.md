# Icon

Lucide outline icons drawn in `currentColor` at a 1.5 stroke, sized to sit beside display labels and serif text.

- **Provide:** `name` (one of the 28 in the set), `size` (24 by default; 18 to 20 inside buttons and labels), and `title` only when the icon stands alone and carries meaning.
- Icons sit next to words. The only icon-only controls are the menu and close toggles, which carry a title.
- Color comes from the parent: `ink`, `ink-on-dark` or `danger`. Don't fill icons or change the stroke weight.
