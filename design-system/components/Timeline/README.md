# Timeline

The history of the Cross, year by year, with the dotted O as the marker.

- **Provide:** `items`, each with a `year`, `title`, `text`, and an optional archival `image`, `imageAlt` and `caption`.
- Years are set in display figures. Keep titles short and active, and keep dates exactly as the history sources give them.
- Archival photos are small originals. Show them no wider than 340px.
