# ChoiceChips

A single-choice radio group drawn as chips, for time blocks, event types and gift amounts.

- **Provide:** `label`, `name`, `options` (each a `value`, `label` and optional `note`), either `value` with `onChange` or a `defaultValue`, and `columns` for an even grid.
- Use for two to six short options. Use a `select` Field for longer lists.
- The checked chip turns navy with a check mark, so the choice never relies on color alone.
