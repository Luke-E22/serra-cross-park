# Button

The site's one button: a short verb label in display capitals on a square-cornered block.

- **Variants:** `primary` (navy) for the main action on a view, like "Plan your wedding" or "Send inquiry". `give` (ochre) only for donating and paying site fees. `secondary` (outline) for the alternative beside a primary. `link` for quiet actions inside text-heavy layouts.
- **Provide:** `children` (two to four words, verb first), an optional `icon` (`arrow-right` for moving forward, `hand-heart` for giving; `give` puts its icon first), `size="lg"` in heroes and form footers, `onDark` on navy grounds and photos, and `href` to render a link.
- One `primary` per view. Keep `give` for money so it always means giving.
- Write labels in sentence case; the style sets the capitals. No exclamation marks.
