# FAQList

Questions couples and visitors ask, as an accordion.

- **Provide:** `items` (each a `q` and an `a`) and `defaultOpen` (an index; -1 closes all).
- Write questions in the visitor's words. Start each answer with the answer: "No." or "Yes, with a licensed caterer."
- On the FAQ page, group lists by topic: Booking, On the day, Visiting.
