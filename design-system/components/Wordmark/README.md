# Wordmark

The park's name set live in Strong Glasgow capitals, with the Serra Cross Conservancy line for formal places.

- **Provide:** `size` (`sm` in the header, `md` inline, `lg` in the footer), `tone` (`ink` on light grounds, `paper` on navy and photos), `nonprofit` to add the Conservancy line (`lg` only), and `href` to make it the home link.
- Use the live wordmark in the site header and footer. Use the SVG files in Logos for social images, email signatures, print, and anywhere the web font can't load.
- Keep clear space equal to the cap height on every side.
- Don't set the name in another face, color it anything but navy or paper, add a cross symbol, or stack it with other logos.
