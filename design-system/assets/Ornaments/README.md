# Ornaments

The dotted O from Strong Glasgow, as shapes. Not icons, and not part of the logo.

- `dotted-o-ochre.svg` (ink `ochre`, #a97b47), `dotted-o-navy.svg` (ink `navy`), `dotted-o-paper.svg` (ink `paper`): the mark alone. Bullets for print, favicons, social stamps.
- `ornament-rule-ochre.svg`, `ornament-rule-navy.svg`: a 480px divider with the mark centered. Print and email; on the web use the `Ornament` component.
