# Icons

Lucide v0.469.0 (ISC license), 24px grid, 1.5 stroke, round caps. These files are drawn in ink `navy` (#1d2944) for use in `<img>`. In code, use the `Icon` component, which draws the same set in `currentColor`.

Set: arrow-right, arrow-up-right, chevron-down, menu, x, plus, minus, check, circle-alert, info, calendar, clock, users, map-pin, sunset, accessibility, toilet, droplet, plug-zap, wine, shield-check, car, lamp, mail, phone, facebook, hand-heart, landmark.
