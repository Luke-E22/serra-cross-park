# Logos

Outlined from Strong Glasgow Bold, so they render without the font. Navy files are ink `navy` (#1d2944) for light grounds; paper files are ink `paper` (#f4f1ea) for navy grounds and photos.

- `wordmark-navy.svg`, `wordmark-paper.svg`: SERRA CROSS PARK on one line. The default logo. At least 120px wide on screen.
- `lockup-navy.svg`, `lockup-paper.svg`: the wordmark over SERRA CROSS CONSERVANCY between rules. Use where the nonprofit must be named: donation receipts, letters, grant documents. At least 200px wide.
- `stacked-navy.svg`, `stacked-paper.svg`: SERRA / CROSS / PARK justified to one width. Use for square spaces: social avatars, stamps, signage tiles.
